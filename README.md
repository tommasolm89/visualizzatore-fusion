# Visualizzatore Fusion

Visualizzatore per tablet dei modelli Fusion 360: componenti con joint mobili, sezioni, misure e note.

- App: https://tommasolm89.github.io/visualizzatore-fusion/
- I modelli si esportano da Fusion con lo script `FusionViewerExport` (cartella `fusion-script`).
- I file aperti restano solo sul dispositivo: niente viene caricato online.
